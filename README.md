# STORY_STORE – Standalone Story Store Platform

A modern, full-featured online e-commerce platform for books, novels, thrillers, fantasy classics, and literary merchandise.

## Features
- **Storefront & Catalog**: Browse books by category, genre, language, price, and rating.
- **Cart & Wishlist**: Interactive cart management and wishlist functionality.
- **Checkout & Digital Receipts**: Streamlined checkout with instant PDF receipt generation.
- **Customer Portal**: Account registration, order history tracking, reading progress, and rewards.
- **Admin Dashboard**: Comprehensive inventory management, sales analytics, delivery tracking, review moderation, and offer management.

## Setup & Local Execution

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Application**:
   ```bash
   python app.py
   ```
   The application runs locally on **`http://127.0.0.1:5001`**.

## Database
Uses SQLite (`story_store.db`) for lightweight, zero-configuration local deployment.
